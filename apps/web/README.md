# picciuli-web

Web, desktop and mobile front-end of [Picciuli](../../README.md): a React and
TypeScript Progressive Web App on top of the [API server](../api/README.md).

```bash
npm ci
npm run dev        # http://localhost:5173 (production API and login)
npm test
npm run build
```

See the [user and developer guide](../../docs/web.md).
