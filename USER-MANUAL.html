About Picciuli

Picciuli is an offline, terminal-based personal finance tracker. It stores data in a SQLite file you choose, and summarizes cash flows by category and reporting period.

All monetary amounts are stored as integer cents. Positive cash flows are income; negative cash flows are expenses. A category balance is the signed sum of its cash-flow items. Parent categories roll up their children in period summaries.

Demo data is illustrative. The manual’s figures reflect demo.db as generated for November 2026. Your dates and balances will differ if you generate a fresh demo at another time or edit the database.

Install and launch

Requirements

  • Python 3.10 or later
  • A terminal with keyboard input and ANSI color support
  • The Python dependencies listed in requirements.txt (Blessed, SQLAlchemy, and Matplotlib)

Open a terminal in the Picciuli project folder. Create and activate a virtual environment, install dependencies, and start a database:

python3 -m venv .env
source .env/bin/activate
python -m pip install -r requirements.txt
python main.py finance.db

On Windows PowerShell, use the platform-specific activation command:

py -m venv .env
.\.env\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py finance.db

The database is created automatically the first time you open it. Reuse finance.db on later launches to continue with the same data. To make the showcase database instead, create it once and then open it normally:

python main.py --demo demo.db
python main.py demo.db

The --demo command exits after creating the database. It refuses to overwrite an existing file; choose another filename or move the existing file yourself.

Keep a backup by copying the database file while Picciuli is closed. Treat that file as your financial record; it is not uploaded or synchronized by the application.

Read the overview

The overview is the main screen. It shows the selected date, days with cash flows, transactions on the selected day, balances in the selected period, budget room where budgets are assigned, and separate loan and savings totals.

Move around the calendar

  • Use ←/→ to move one day and ↑/↓ to move one week.
  • Use [ and ] to move to the previous or next month.
  • If more than one period includes the selected date, use < or > to switch the balance panel between them. The demo’s November date is in both “Year overview” and “November 2026”.
  • The selected date’s transactions appear in the middle panel. Use j/k to select among them.

The overview reports loans pending and savings accrued separately. These values are not combined into a net-worth calculation.

Add, edit, and delete cash-flow items

A cash-flow item is an income or expense on a date, assigned to a category. Choose a day with the calendar, press a, then enter a description, amount, and category. Use positive numbers for income and negative numbers for expenses; amounts can have up to two decimal places.

  1. Navigate to the date of the transaction.
  2. Press a and enter a description (you can leave it blank).
  3. Enter the signed amount, such as 48.00 for income or -12.50 for spending.
  4. Choose a category by its number from the displayed list.
  5. Press j/k to select an item on the day. Press e to edit or d to delete it; confirm deletion by typing y.

In the demo, the November 7 “Design project” payment is +$480.00, while groceries are -$440.00. The selected date’s category symbol is shown beside each item.

Loan payments and savings contributions also appear here as expenses. Link one to a goal when creating the item; do not enter a second ordinary expense for the same payment.

Organize spending with categories

Categories group the cash flows shown in the overview and reports. Picciuli supports top-level categories and one level of subcategories. Each category has a short display symbol, and list order is used in summaries and selection menus.

  1. Press c on the overview to add a top-level category.
  2. Press m to open category management.
  3. In management, use the arrow keys to select a category. Press c to add a top-level category or s to add a subcategory under the selected parent.
  4. Use e to edit or d to delete. Use j/k to reorder within the category’s group.

The demo uses top-level categories such as Income, Home, Food, Transport, Goals, and Health. For example, Groceries and Dining roll up into Food; Rent and Utilities roll up into Home. Reports show the parent subtotal and the child detail without double-counting the total.

Delete child categories before deleting their parent. A category with cash flows cannot be removed until those cash flows are reassigned or deleted.

Periods and category balances

A period defines the date range used to summarize cash flows and budgets. Periods can overlap, which lets you compare a month against a year-to-date or other custom range.

  • Press n on the overview to start a period on the selected day.
  • Press r to rename a period that covers the selected day.
  • Press p to manage all periods: arrow keys select; a adds; e edits; d deletes.
  • For an open-ended range, leave the end date blank when prompted. A new period beginning later closes an earlier open period that started before it.
  • Use </> on the overview to switch between overlapping periods for that date.

The demo contains “Year overview” for 2026 and monthly periods from August through November. On November 7, the selected date belongs to the year period and the open-ended November period. The current monthly balance totals $1,135.00: $3,730.00 of income offset by $2,595.00 of expenses recorded through that date.

Plan with budgets

Press b to manage budgets. Press a, choose a period and category from the numbered lists, then enter a non-negative amount. Select a row to edit it with e or delete it with d and confirm with y.

On the overview, an assigned budget is shown beside its category balance as “left / budget left.” A parent category’s balance and budget include its subcategories. In a report, the budget status shows the assigned amount and remaining or overspent amount. Because cash flows are signed, income in a budgeted category offsets its expenses.

Track loans and manual repayments

Press l to open loan management. Use the up/down arrows to select a loan; press a to add one. The screen shows remaining principal, original amount, percent repaid, total interest paid, and payment history. Use j/k or Page Up/Page Down to scroll the history.

Record a repayment

  1. Create the loan from l → a by entering a name and original amount.
  2. Return to the overview, choose the payment date, and press a.
  3. Enter a description, select the loan from the goal list, and enter the total payment amount.
  4. Enter the principal portion, then choose a category such as Goals → Debt repayment.

Enter the total payment and principal separately. Interest is derived as total payment minus principal. Picciuli records payments manually; it does not calculate interest schedules, due dates, or automatic payments.

Save toward a target

Press t to manage savings targets. Use the arrow keys to select a target, a to add one, and j/k or Page Up/Page Down to review contributions.

Record a contribution

  1. Create a target from t → a by entering its name and goal amount.
  2. On the overview, select the contribution date and press a.
  3. Enter a description, choose the target, enter the positive contribution amount, then choose a category such as Goals → Savings.

The application records the contribution as a negative cash flow. Its target screen shows the positive amount accrued and the remaining progress. A contribution cannot exceed the remaining target amount.

Read and export period reports

On a day covered by a period, press v to open that period’s report. The report groups transactions by top-level categories and subcategories, shows signed subtotals and budget status, and lists loans with principal remaining.

Use the up/down arrows to scroll the report. Press g to choose which category series appear in the graph; the total series always includes every category. Press s to export the report as Markdown and the cumulative-balance graph as PNG under reports/.

The report graph plots cumulative balance over time. In the demo, the total changes from $3,250 after salary on November 1, to $2,100 after rent on November 3, and to $1,135 after the other dated items by November 7.

Optional PDF export

Markdown and PNG are the built-in report exports. To make a PDF, install Pandoc and XeLaTeX, then use the project helper described in Optional PDF.

Currency, database, and practical notes

  • Press u on the overview to change the currency label. It changes how amounts are displayed; it does not convert or recalculate stored values.
  • The database is a SQLite file at the path provided on the command line. Use the same path to reopen it.
  • To create a showcase database, use python main.py --demo demo.db. This command requires a new file path and will not replace existing data.
  • Keep regular backups of your database file. Close the app before copying it for a consistent backup.
  • Loan payments and savings contributions are entered manually. Picciuli does not connect to banks, schedule transfers, or calculate interest accrual.

Management screens

Periods and budgets use the arrow keys to select entries, a to add, e to edit, and d to delete. Category management also uses c for a top-level category, s for a subcategory, and j/k to reorder. Loan and savings screens use a to add a goal and j/k or Page Up/Page Down to scroll history. Press Esc or q to return from a management screen.

Optional: create a PDF report

The report screen saves Markdown and PNG. The included PDF helper uses Pandoc and XeLaTeX. On Debian or Ubuntu, install them with:

sudo apt install pandoc texlive-xetex fonts-dejavu-core

Convert an exported report (the graph is resolved relative to its Markdown file):

scripts/report-to-pdf.sh reports/period-5-November-2026.md

The PDF is written beside the Markdown file. To choose another destination, supply a second argument:

scripts/report-to-pdf.sh reports/period-5-November-2026.md ~/Documents/november.pdf

Use the actual Markdown filename created by your export; it may differ if you changed the period name.
